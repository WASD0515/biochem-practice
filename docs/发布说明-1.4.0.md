# 生化练习室 1.4.0

面向生物化学课程与模拟考试的离线练习应用，支持Android8.0+与Windows10/11 x64。

- 题库更新至风险修复第五版，共2433题（安全429、待确认2004），未明确归属的114题放入其他章节，清理旧非生化题残留。
- 新增待确认练习开关、单题与批量删除、统一库存/可练/题型统计及完整无限刷。
- 每日计划支持剩余天数、自动建议与自定题量，考虑章节与题库模式。
- 模拟考试严格按所选章节抽题，支持随时交卷；考试通过概率按设置范围使用可信题记录估计。
- 本仓库公开界面介绍、安装说明、八题型模板、AI整理提示词、导入教程及版本题库目录。

## 下载

Android请选择APK；Windows Intel/AMD 64位请选择Setup-x64.exe；源码请选择Source-1.4.0.zip。另附教师模板与AI提示词压缩包、当前题库JSON和SHA256校验表。

升级前先在应用导出备份。安卓沿用原签名；Windows安装包未使用商业代码签名。核心逻辑、网页界面、包内资源与安卓签名已验证；尚未在安卓和Windows真机完成安装运行验证。

待确认题为参考练习与自评，不进入可信通过概率。概率未经真实成绩校准。当前没有内置在线AI识别或多教材切换。
