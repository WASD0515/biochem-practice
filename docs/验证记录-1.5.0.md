# 生化练习室 1.5.0 验证记录

## 待确认统计

- 全新安装和旧版迁移均默认关闭待确认统计；练习开关与统计开关互相独立。
- 开启时，所选章节安全客观题首次作答和八题型待确认题首次自评使用同一统计入口；首页、概率、薄弱点、学习报告一致标示来源与样本数。
- 验证示例：安全题首次1分、待确认首次0分及0.5分，关闭时安全正确率100%、样本1；开启时综合首次得分率50%、样本3，概率随之更新；关掉后恢复原结果，记录保留。
- 旧版reviewRecords缺少first时，从历史取最早可用自评；重刷不增加样本。备份与重启保持开关和记录。同一次首次考试自评分修正同步更新首次统计。
- 范围外、已删题、非法分数不纳入；仅待确认章节在开启统计后可评估；安全主观题仍不参与拟合。
- 概率保持掌握程度模型与主观得分率假设，开启时待确认自评只作为掌握程度样本，不额外叠加为试卷主观分数。结果标注含未核实自评，未经真实成绩校准。
