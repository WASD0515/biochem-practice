# 专项练习使用说明（1.7.0）

底部或侧边栏点击“专项练习”，可选“题型专项练习”或“章节练习”。两条入口共用同一组筛选，顺序不影响结果。

## 按题型开始

选择题型专项 → 点单选题（或其他题型） → 在章节筛选中选择“氨基酸、肽和蛋白质” → 开始顺序、随机或未做题练习。只会出现该章的指定题型。

也可先在题型列表选择章节，查看这章每一种题型的可练数，再进入题型。8种题型全部保留：单选、多选、判断、填空、名词解释、简答、论述、记忆卡。

## 按章节开始

章节练习 → 点具体章节 → 在题型筛选中选择填空题 → 开始练习。再切换到“题型专项练习”时，刚才选中的章节和题型仍在。

单章筛选适用于集中复习。需要多个章节时，将单章筛选改为“全部章节”，使用“调整考试章节范围”勾选多个章节；该范围也会影响首页、每日练习、无限刷及之后生成的模拟卷，保存前页面会明确说明。

## 如何理解数量

“当前专项范围”显示最终可练题数：考试章节范围 × 当前章节 × 当前题型 × 安全/待确认开关 × 搜索条件。

- 题型卡片的“当前可练”按所选章节、考试范围及待确认开关计数；卡片本身对应的题型替换上方题型选择，因此可点另一题型。
- 章节卡片的“库存”按所选题型和搜索统计本章库存（含暂不可练的待确认题或范围外题）；“当前可练”进一步应用考试范围和待确认开关。
- 未设置考试章节范围时覆盖全部章节；明确取消全部章节并保存时可练数为0。关闭待确认时，其题目仍可查看/管理，但不会进入练习。
- 无可练题时提示原因并禁用开始按钮，不会自动补入其他题型或章节。
- “只练未做题”进一步去除已有作答记录；安全与待确认题各使用对应记录。

两个入口下的题型、章节选择会保留在本机，并随学习备份保存与恢复。搜索词为临时筛选，重新进入模块时清空。“清除专项筛选”清除专项题型、单章与搜索条件，保留已设置的考试章节范围。

## 与其他功能的关系

专项选择不会修改模拟卷题型配置、首页每日目标或首页无限刷范围。仍可在专项中使用练习开关与原有题目查看、单题/批量删除。练习进度中的题号、即时答案、错题巩固规则不变。

已暂存练习按开始时的题目集合继续，不会被之后的专项筛选重新选题。题目被删除、题库更新、考试章节范围或待确认练习开关改变时，仍使用原有的会话失效/结束规则。不同平台记录独立，可通过学习备份迁移。
