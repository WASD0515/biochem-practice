# 题库格式规则 · 1.4.0

推荐 UTF-8 JSON。完整可导入例子见 [八题型模板](../templates/questions-8-types.json)。模板中的示例会作为真实题目导入，制作正式题库时请替换。

## 文件与字段

```json
{"version":"teacher-2026-01","chapters":["其他章节"],"questions":[{"id":"school-001","topic":"氨基酸、肽和蛋白质","type":"single","stem":"题干","options":[{"key":"A","text":"选项甲"},{"key":"B","text":"选项乙"}],"answer":["A"],"explanation":"原解析或空字符串","source":"文件名·原题号","status":"active","reviewReason":""}]}
```

|字段|规则|
|---|---|
|version|教师自定版本标记，便于追溯|
|chapters|声明新增章节；固定教材章节不用重复声明|
|questions|题目数组|
|id|建议必填，稳定且唯一；使用英文字母、数字、短横线、下划线，1–120字符；同ID更新|
|topic|与[章节目录](../templates/chapters.txt)或自建章节精确匹配；不确定时用“其他章节”|
|type|下表八种之一|
|stem|非空题干，保留否定词、数值、单位、公式、上下标和材料关系|
|options|选择/判断题选项数组，key不可重复；其他题型使用空数组|
|answer|按题型定义，不得混写键值与答案正文|
|explanation|来源解析，可为空；不要将AI补充冒充原解析|
|source|文件名及可靠的原题号/页码，不编造出处|
|status|active或review；有疑点、缺图、缺答案、答案配对不明时用review|
|reviewReason|待确认原因；没有疑点时可为空|

`active`不等于已人工审定。`review`不自动启用；开启“允许练习待确认题”后可参考练习和自评，但不进入可信通过概率。

## 八种题型

|type|中文|options|answer示例|反馈方式|
|---|---|---|---|---|
|single|单选|选项键/正文数组|`["A"]`|安全题自动判分|
|multiple|多选|选项键/正文数组|`["A","C"]`|安全题自动判分|
|judge|判断|A=正确、B=错误|`["B"]`|安全题自动判分|
|fill|填空|`[]`|`[["TPP","硫胺素焦磷酸"],["FAD"]]`|安全题逐空匹配|
|definition|名词解释|`[]`|`["参考定义"]`|参考答案后自评|
|short|简答|`[]`|`["要点一","要点二"]`|参考答案后自评|
|essay|论述|`[]`|`["参考论述与评分要点"]`|参考答案后自评|
|flashcard|记忆卡|`[]`|`["记忆内容"]`|参考答案后自评|

填空每个内层数组对应同一空的同义答案，顺序与空位对应。不确定的不同答案不能当作同义词。缺乏可靠来源答案时可用空answer并标review，不能把AI推测写成正式答案。

当前模拟卷设置提供名词解释、填空、单选、判断、简答、论述六类；多选和记忆卡用于章节等练习。分值在模拟卷设置中配置，不固化于导入文件。

## 更新与去重

同一题长期保留ID，章节重命名、换教材或换文件不要重新编号。相同ID导入会更新已有题，不增加库存；内容/答案发生改变会重置相应旧掌握记录。不同文件出现相同ID应先消除冲突；本地导入预览按唯一ID统计，GitHub单版本跨文件重复ID会拒绝导入。

固定36章不可通过题库导入改名或删除；新增章节可在应用创建，也可通过顶层chapters声明。当前不保存多教材映射或知识点关系，相关AI建议请放独立核对报告。
