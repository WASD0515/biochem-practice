# 教师题库导入教程

## 最少操作流程

1. 下载[八题型模板](../templates/questions-8-types.json)，或使用 [AI提示词](../ai/AI整理提示词.txt) 整理已有资料。
2. 得到UTF-8的“题库.json”和“核对报告.md”。先核对题数、缺图、缺答案与章节不明条目。
3. 应用 → **题库管理 → 选择题库文件**，可选JSON、规范TXT、CSV或DOCX。
4. 查看预览中的有效题、待确认题、格式错误、更新与新增数量，确认后合并。发生错误时先修复，不凭导入成功认定答案正确。
5. 到章节练习检查少量代表题，再向学生分发。

JSON是推荐发布格式；TXT/DOCX识别依赖格式，复杂公式、图片与跨页材料建议先整理成JSON。基础Word模板仅作结构示例，不代表支持任意Word排版。

## 章节与审核

使用[固定章节精确名称](../templates/chapters.txt)。自定义章节在顶层chapters声明；不明确归属用“其他章节”，同时status=review并写原因。单个文件可包含多个章节，导入后按topic自动分发。

默认只练active题。首页开启“允许练习待确认题”后也能练review题；这些题始终参考作答/自评；是否纳入综合首次得分率、通过概率与薄弱点，由“将待确认题纳入正确率与通过概率”独立开关决定，默认关闭。教师核查后可在题库管理编辑并更改审核状态。

## 数量为什么不同

库存是所有未删除的题；可练数还取决于章节范围和待确认开关；模拟卷每行显示该题型在选定范围内的数量。已练/今日完成按实际完成的唯一题计数，重复刷不重复累加，未答交卷不算已练。刚安装时库存2433，默认可练429，开启待确认后可练2433。

在选章窗口可“一键全选”“全部取消勾选”，或“不限制章节”。取消全部并保存表示空范围；不限章节表示全部适用题。

## 更新、删除与替换

- 同ID合并更新；新ID新增。请保留稳定ID避免同题重复。
- 章节练习 → 某章 → 可单题删除，也可勾选后批量删除。“全选当前筛选”包含后续分页。
- 题库管理上方“题目清理”可按章节清除或清空所有题目，操作前导出备份。
- 完全替换某套题库：先导出学习备份，清空题目，再导入新版本。手动导入可能恢复此前删除的同ID题，请先核对。
- 学习备份包含个人作答记录，应留在教师/学生自己的设备，不提交到公开GitHub。

## 从本仓库一键导入

应用 → 题库管理 → GitHub题库版本，填写用户名WASD0515、仓库biochem-practice、分支main、目录data。点“保存并读取版本”，再选目标版本“一键导入”。无需访问令牌，不上传学生记录。

当前biochem-v5为第五版2433题，与1.5.0内置版本一致。所有文件通过校验后才一次性应用，下载失败不会导入半套题库。

## 教师维护新的发布版本

本仓库目录示例：

```text
data/
  index.json
  biochem-v5/
    questions.json
  teacher-v2/
    questions.json
```

新增版本时创建英文/数字/短横线/下划线命名的文件夹，把JSON放入其中，并向index.json的versions追加：

```json
{"id":"teacher-v2","title":"教师题库第二版","description":"范围、题量和审核说明","files":["teacher-v2/questions.json"]}
```

id必须与目录名一致；files相对index.json，最多20个JSON文件、单版本最多10000题、单文件不超过15MB。跨文件ID不得重复。保留原版本方便追溯，更新索引后学生重新读取即可看到。

## 常见问题

- **缺题/少题**：检查是否关闭待确认、限制了章节、按题型筛选、之前删除或同ID更新。
- **无法组卷**：查看选定章节每题型可用数量，减少该题型数量或扩大范围；不会从范围外补题。
- **来源缺答案**：保留review及原因，先人工核对；不要为了可以自动判分而随意标active。
- **GitHub读取失败**：确认仓库公开、分支/目录准确，网络能访问GitHub原始文件；也可下载JSON后手动导入。
- **换设备**：在原设备导出学习备份，在新设备恢复；两个平台不会自动同步。
