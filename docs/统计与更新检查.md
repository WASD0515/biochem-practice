# 待确认统计与软件更新 · 1.5.0

## 两个互相独立的开关

|开关|作用|默认|
|---|---|---|
|允许练习待确认题|控制章节、每日计划、无限刷和模拟卷是否允许review题|关闭|
|将待确认题纳入正确率与通过概率|控制首次得分率、通过概率及薄弱点是否纳入待确认题首次自评|关闭|

入口：首页“练习与考试章节范围”卡片、概率详情、章节页、模拟卷设置；“设置 → 统计口径”也可调整。关闭练习开关不删除以往记录，已练待确认题仍可由统计开关纳入。

开启统计后，首页改显示“综合首次得分率（含待确认自评）”；概率卡片与报告列出安全客观题数和待确认自评数，避免把混合数据误认为全部已核实。关掉开关立即恢复安全客观题口径，不删除任何记录，也不更改题目active/review状态。

## 具体计算方式

- 默认使用所选章节安全客观题首次作答；安全主观题自评不参与拟合。
- 开启后，八种题型的待确认题首次自评也作为掌握程度样本；按0–1得分比例计入，仍按题ID去重。
- 从旧版历史记录中恢复最早可用自评；找不到历史且没有首次分数时，不把“最新重刷分数”冒充首次成绩，待后续留下可用记录。
- 一道题反复刷不会增加独立样本量。概率和首次得分率使用首次分数，薄弱点使用最新分数及错题状态；修正同一次考试的首次自评分会同步修正首次统计。
- 只计当前所选章节、尚未删除的适用题目。未确认考试范围时仍不显示个人通过概率；练习开关不改变已保存统计数据的纳入授权。
- 每章Beta(2,2)掌握程度模型以首次比例更新；预测等权知识检查点并映射到客观总分，主观部分仍按用户设置的得分率假设计算。待确认主观自评是掌握程度证据，不同时直接作为试卷主观得分叠加。
- 模型未经真实考试校准；纳入待确认题与自评也不等于题目已核实，结果仅作复习参考。

## 检查更新

设置 → 软件更新 → 检查更新。显示当前版本、最新正式版本、更新说明与下载按钮。安卓使用APK，Windows使用Intel/AMD x64安装包；网页端提供版本页链接。

“启动时检查更新”默认开启，可关闭。启动检查失败不弹窗、不打断学习；有新版本时仅提示到设置查看，进行中的练习和考试不会被更新弹窗打断。

版本查询优先读取本仓库公开`app-update.json`；不可用时尝试GitHub最新正式Release接口。只发送版本查询，不上传题库、学习记录或学生信息。网络不可用时练习不受影响，可稍后重试或打开GitHub下载页。

点击下载会通过系统浏览器打开本项目GitHub Release附件，应用不会自动安装。升级前导出学习备份；正式安卓包须沿用相同签名才能覆盖安装。
