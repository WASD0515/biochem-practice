# 苹果设备安装与使用

## iPhone / iPad：无需 App Store

正式地址： https://wasd0515.github.io/biochem-practice/dist/

1. 在 Safari 打开上面的地址。微信内置浏览器中请先选择“在 Safari 中打开”。
2. 点分享按钮，选择“添加到主屏幕”；若有“作为网页 App 打开”选项，请开启。
3. 点主屏幕上的“生化练习室”图标，联网等待顶部显示“离线已就绪”。首次加载需要下载完整资源，之后可离线刷题、看答案、练错题、模拟考试。
4. 正式练习尽量在主屏幕应用里进行。Safari 与主屏幕应用的记录可能独立，不同设备也不自动同步；用设置里的学习备份迁移。

建议 iOS / iPadOS 16.4 及以上并更新 Safari。此版本为可安装网页应用（PWA），不提供可直接侧载的 IPA，不需要苹果开发者付费账号或定期重签名。首次加载、获取新版或在线题库需要网络。GitHub Pages 在部分网络访问较慢，可将 dist 完整目录原样放到学校自己的 HTTPS 静态网站；更换网站地址会形成新的本地学习空间，请先导出备份。

这与原生 iOS 安装包不同：原生包即使不上架也需要合适的苹果签名/分发方式；免费 Personal Team 主要用于个人测试，描述文件通常7天到期，不适合向整班长期分发。将来如需 TestFlight 或 App Store，可在取得 Apple Developer 账号后继续制作原生分发版本。

[苹果官方主屏幕安装步骤](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios) · [苹果开发者账号与个人测试限制](https://developer.apple.com/help/account/basics/about-your-developer-account/)

## macOS：独立应用

在项目 Release 下载 `Biochem-Practice-1.6.0-mac-universal.dmg`，打开后将“生化练习室”拖入 Applications（应用程序）。也提供 ZIP，解压后移动到应用程序。

- 支持 macOS 12.3+，同一个安装包含 Apple Silicon arm64 与 Intel x86_64。
- 内置2433题（安全429、待确认2004），首次启动无需下载题库。默认只练安全题，两个待确认相关开关与其他平台一致。
- 导入文件时使用系统文件选择器，支持 JSON、CSV、TXT、DOCX。导出备份使用原生保存窗口。
- “题库管理”可选择教师文件夹，应用运行期间每30秒检查更新；关闭后停止，重启需重新选择文件夹。
- 学习数据由 macOS WebKit 保存在此应用本地，更新前导出备份。与网页版不自动共享。
- 当前只有 ad-hoc 完整性签名，没有 Apple Developer ID 签名与苹果公证。系统或学校策略可能阻止打开；请遵循设备安全策略，也可直接使用网页版本，无需修改系统安全设置。

## 数据备份与题库导入

设置 → 导出学习备份。iPhone 优先调起系统分享菜单，选择“存储到文件”；不支持文件分享时使用浏览器下载。恢复时点“从备份恢复”，从“文件”选 JSON 并确认。跨设备不会自动传输数据，备份含个人学习记录，请自行保管，不要上传公开仓库。

题库管理 → 导入题库，从“文件”选择题库文件，检查预览后确认。格式、题型、审核与统计规则不变，详见题库导入教程。

网页离线缓存不等于永久备份。卸载图标、清理网站数据、无痕浏览或系统存储回收都可能影响可用性。正式考试前请先打开检查可用，并定期导出学习备份。“尝试保留离线数据”可申请浏览器持久存储，但浏览器不一定批准。

## 更新

- Mac：设置 → 软件更新 → 检查更新，下载对应 Mac 的 DMG，导出备份后手动替换应用。
- iPhone：联网打开设置 → 检查网页更新。新资源全部就绪后显示“更新网页应用”，点击才刷新；进行中的模拟卷请先交卷。正常更新保留学习记录。
- 网页仅缓存本应用目录的固定资源，不缓存在线题库响应；缓存清理只清理自身版本，不删除同域其他应用缓存。

## 网站部署

仓库 Settings → Pages → Deploy from a branch → main → / (root)。根 index.html 跳转到 dist；_config.yml 排除开发资料，dist 保留相对路径。每次更新 dist 后 GitHub Pages 自动重新部署。自建网站时直接将 dist 内容放到 HTTPS 目录即可，无需 Node 服务端、数据库或密钥。
