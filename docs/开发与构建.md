# 开发与构建

## 网页预览与测试

dist目录即应用可运行资源，无需前端编译。安装Node.js后：

```sh
node tools/test.cjs
python3 -m http.server 8765 --directory dist
```

浏览器访问 http://localhost:8765 。学习记录在浏览器本地存储。生产网页需要HTTPS或localhost才能使用离线服务功能。

可选界面回归：安装Playwright及Chromium（仅开发测试依赖），运行 `node tools/ui-test.cjs`。该测试会在release目录写截图；不需要连接真实学生数据。

## Windows x64

安装Node.js和pnpm。项目锁文件使用pnpm：

```sh
pnpm install --frozen-lockfile
pnpm run build:win
```

输出到release/windows。使用Electron Builder的NSIS目标，建议在Windows x64构建；在其他系统交叉构建需要该工具支持的相应环境。官方Release已提供可直接安装的exe。

## Android

安卓外壳为Java WebView，最低Android8.0/API26，target35。需要Python3、JDK及Android SDK（平台35，build-tools35或更新可用版本）。配置环境变量：

- JAVA_HOME：JDK路径。
- ANDROID_SDK_ROOT：Android SDK路径。
- ANDROID_BUILD_TOOLS_VERSION：可选，默认35.0.0。
- BIOCHEM_KEYSTORE：你自己的签名文件路径。
- BIOCHEM_KEY_ALIAS：签名别名。
- BIOCHEM_STORE_PASSWORD、BIOCHEM_KEY_PASSWORD：签名密码，仅从本机环境读取。

运行 `python3 tools/build_android.py`。密钥及密码不在公开仓库中；自行构建的不同签名APK不能覆盖官方签名安装，应另用设备/卸载安装并先备份。正式Release仍由维护者保管的原签名发布。

## 题库更新

source-data保存第五版JSON及核对报告，`tools/replace_bundled_bank.cjs`规范化章节、生成dist/question-bank.json和bank.js，保留审核状态及稳定ID。此脚本针对当前批次；换批次需修改输入文件、版本标记及相应回归断言。

发布前运行逻辑测试、浏览器回归、校验实际题数与选章组卷，重新打包两个平台并核对签名。模板能通过结构校验不代表生物化学答案已经由教师审定。

## 1.5.0新增检查

核心测试入口会同时执行test-150.cjs。新增界面回归为node tools/ui-test-150.cjs，使用模拟公开版本响应验证更新检查和平台下载交接，不执行安装。dist/update.js维护当前软件版本，app-update.json维护已发布版本与附件地址；发布新版本时同时核对package.json、AndroidManifest和服务缓存版本。具体顺序见统计与更新检查.md。

## macOS 与 iPhone（1.6.0）

macOS 安装完整 Xcode 后运行 `python3 tools/build_macos.py`。无需额外下载 Electron；使用 AppKit + 系统 WKWebView 载入同一套 dist。脚本编译 arm64 与 x86_64 后合并，制作 ad-hoc 签名的 APP、DMG 与 ZIP，输出 release/macos。签名不是 Developer ID 或苹果公证。

iPhone 使用 dist 内的可安装离线网页应用，无需编译 IPA。安装、HTTPS 部署和数据迁移见苹果设备安装与使用.md。新增 `node tools/ui-test-160.cjs` 检查子目录缓存、离线重开、版本切换和考试保护；可与之前两套界面测试一并运行。

Mac 可执行文件带开发检查入口：`生化练习室.app/Contents/MacOS/BiochemPractice --smoke-test /绝对路径/report.json`；只在显式传参时运行。连续启动两次可检查 persistedAcrossLaunch。不要将学习记录或本机签名凭据加入源码包。
